THE PROCESS

What EyeCare observes

01

Blink patterns

Eye landmarks are used to estimate the Eye Aspect Ratio and identify blink events.

02

Viewing distance

After calibration, iris landmark separation is used to estimate distance from the screen.

03

Screen time

Session duration and detected eye-closure time contribute to the Eye Strain Index.

Privacy note

Camera frames are processed by the application server and are not saved as images. Only session summary metrics are stored in the local application database. Use HTTPS when deployed online.
